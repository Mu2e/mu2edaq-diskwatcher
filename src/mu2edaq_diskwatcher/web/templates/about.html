About
mu2edaq Disk Watcher v{{ app_version }}

Monitors files and directories for three independent conditions and raises a distinct alarm state for each:

  • Staleness — the path has not been modified within its configured delay.
  • Free space — a directory's filesystem has fallen below a space: threshold (Disk Space).
  • File size — a file is zero length or has grown past a size: threshold (File Sizes).
